# Terminal Portfolio

This is a terminal portfolio made with vanilla JavaScript and the used packages are termina-kit, and figlet.

## Used Packages :

- _Terminal-kit_
- _Figlet_

## To Run This

```bash
npx senapati
```

### Local installation

```bash
git clone https://github.com/Senapati5/Terminal-Portfolio.git
```

```bash
cd Terminal-Portfolio
```

```bash
npm i
```

### Start

```bash
node index.js
```

### Publish To npm

```bash
npm login
```

```bash
npm publish
```

(make sure to change the name in package.json before publishing)
(node latest version needed in ubuntu or linux)
